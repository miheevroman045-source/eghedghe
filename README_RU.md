# SIFT DIMENSION 2.0 — SCULKITE EXPANSION

**Minecraft Java Edition 1.21.1 / Fabric / Java 21**. Это полный исходный проект мода для сборки через GitHub Actions. Не путайте ZIP с игровым JAR: ZIP содержит исходный код и текстуры. Базовый Sift v1 сохранён и расширен.

## Внутри

- Три биома измерения Sift: Разбитые пустоши Сифта (Shattered Wastes), Скалковые полости (Sculk Hollows), Эхо-поля (Echo Crystal Fields). Распределяются через `multi_noise` в новых чанках.
- 18 новых блоков: скалковый камень и его архитектурные варианты, скалковая почва, мох, теневой базальт, сланец бездны, светящиеся блоки, эхо-стекло и три варианта рудных блоков.
- Настоящие жилы скалкитовой и эхо-руды внутри мира; поверхностные участки новых блоков и кристальные шпили.
- Материалы: сырой скалкит, слиток скалкита, эхо-самоцвет, ядро бездны, скалковая пыль, скалковое сердце.
- Меч Скалкита и Эхо-клинок. Скалкитовая кирка, топор, лопата, мотыга.
- Скалкитовая броня: шлем, нагрудник, поножи, ботинки. Собственная текстура 64×32 для двух слоёв брони.
- Зачарование `sift:sculk_hunter` — «Скалковый охотник» I–III. Добавляет урон по целям: +1,5/+2,5/+3,5 единицы, доступно через стол зачарования (при поддержке тегов мечей).
- Бонус **«Скалковый резонанс»**: в полном комплекте скалкитовой брони и со скалкитовым мечом в основной руке атака получает **+10** к базовому урону. Урон меча в обычном состоянии — 10, с комплектом — 20 до зачарований, эффектов, критов и защиты цели. Действует только для этого меча, сразу пропадает при снятии брони. Это удвоение базового урона, а не удвоение итогового HP-урона сквозь сопротивления.
- Дополнительная защита и ночное зрение в Сифте в полном комплекте.
- Эхо-клинок даёт временную скорость во время путешествия по Сифту.
- Сохранены портал Древнего города, обратный портал, тьма, безопасные кристаллы, стражи и руины. В сундуках руин появились новые ресурсы и редкое снаряжение.

Значения базового урона приводятся без дополнительных зачарований, эффектов, критов и брони цели.

## Получение в выживании

1. В Древнем городе найди арку из укреплённого глубинного сланца. Нажми ПКМ эховым осколком или Ключом Сифта по арке. Пройди в светящийся портал.
2. Исследуй новые территории и шахты. Скалкитовая руда встречается глубоко под землёй; глубокая — реже. Добывай алмазной или более мощной киркой.
3. Переплавь руду или сырой скалкит в печи/плавильне для получения слитков. Сделай из слитков броню и оружие на верстаке.
4. Надень 4 части брони, возьми скалкитовый меч — активируется «Скалковый резонанс» (×2 к базовому урону меча).
5. Ищи «Скалкового охотника» на столе зачарования. Чары добавляют прямой урон отдельным эффектом.

## Команды (права OP / включённые читы)

- `/sift visit` — попасть в измерение Сифт либо вернуться.
- `/sift kit` — тестовые ключ и кристаллы.
- `/sift gear` — получить набор нового оружия, инструментов, брони и материалов.
- `/give @s sift:sculkite_sword` — получить меч.
- `/give @s sift:sculkite_ore 64` — получить руду.
- `/give @s sift:sculkstone_bricks 64` — получить декоративные блоки.
- `/enchant @s sift:sculk_hunter 3` — попробовать зачарование, держа меч в основной руке.

## Сборка через GitHub

1. Загрузи все файлы из ZIP прямо в корень GitHub-репозитория. Не забудь скрытую папку `.github`.
2. Вкладка Actions → **Build Sift Dimension 1.21.1** → запусти workflow вручную или дождись запуска после push.
3. После зелёной отметки скачай **Sift-Dimension-Fabric-1.21.1** в Artifacts. Распакуй ZIP и извлеки игровой `.jar`.
4. Положи `.jar` и подходящую версию Fabric API в папку `.minecraft/mods` на Minecraft 1.21.1 Fabric.
5. Проверь сначала НОВЫЙ тестовый мир, потому что регистрация измерений и параметры генерации изменены по сравнению с версией 1.0.

## Ограничения / честный статус

Исходники созданы и проверены на корректность JSON, наличие изображений, ключи ресурсов и структуру проекта. Здесь Gradle недоступен и нельзя скачать зависимости, поэтому **полную компиляцию, загрузку ресурсов движком и игру на сервере проверить не удалось**. Ошибки компиляции или датапака ещё возможны; при возникновении нужны логи из GitHub Actions или `latest.log`.

Изменение `sift:sift` с фиксированного биома на `multi_noise` может изменять генерацию новых территорий в старых сохранениях. Сделай резервную копию мира.


## Компактная версия для GitHub (13 файлов)

Это тот же мод v2.0. Ничего из блоков, биомов, рецептов, текстур и таблиц лута не удалено.
Все 211 файлов из папок `assets/` и `data/` упакованы в **один** файл
`src/main/resources/sift-content.zip`.

**Не распаковывай `sift-content.zip` при загрузке в GitHub!**
При сборке Gradle самостоятельно разворачивает ресурсы, поэтому итоговый `.jar`
получит настоящие JSON и PNG по исходным путям.

Сборка: GitHub Actions или `gradle --no-daemon clean build`.

Проверка компиляции и запуска игры ещё необходима.
