# Changelog

## v2.0.0 — Sculkite Expansion
- Added 18 new blocks and 16 equipment/crafting items, with textures and localized names.
- Added Sculk Hollows and Echo Crystal Fields biomes to the Sift dimension's multi-noise biome source.
- Added sculkite/deep sculkite/echo ore generation and surface patches.
- Added stronger-than-netherite sculkite tool material: 2548 durability, speed 11 and base sword damage 10.
- Added Sculkite Helmet, Chestplate, Leggings, Boots with armor textures and full-set resonance bonus.
- Added the data-driven Sculk Hunter enchantment I–III.
- Added full item crafting/smelting recipes and ore/block loot tables.
- Expanded Sift ruins loot and added `/sift gear` to test all new equipment.
- Preserved the Ancient City portal, return system, crystal areas, guardians and original ruins.
